FOCUS

Multimodal conditional diffusion for coordinated enhancement of spatial transcriptomics.

The current implementation generates five gene-expression channels together. Its real-condition execution demo reads one registered H&E / observed ST pair from a training tile and writes a five-panel PNG and a five-channel float32 NPZ.
